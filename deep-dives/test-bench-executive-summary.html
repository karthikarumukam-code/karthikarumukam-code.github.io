THE CHALLENGE 02 / 09

Every configuration has to earn its place on the bench.

The test bench is a shared, limited resource — every finished configuration has to pass through it before production. Most cars clear it quickly. Some take far longer, and today there's no way to know which, until the car is already sitting on the bench.

WHAT ACTUALLY MATTERS 05 / 09

A handful of choices make almost all the difference.

We tested this directly — hiding one configuration choice at a time to see if it changed the prediction. Result: the vast majority make no difference at all. Just a couple of choices explain almost everything.

  • One configuration type is harder to call — it's rare in our history, so predictions for it carry more uncertainty. Worth an extra buffer, not blind trust.
  • Some variation can't be explained by configuration at all — a number of cars with identical setups still show real differences in actual test time, by up to a minute. Worth an operational look — likely the process or equipment, not the tool.

WHAT WE ACTUALLY BUILT 07 / 09

A review tool.

Automatically flags every past car whose predicted time missed the real outcome by more than 5%, so an engineer can review each one, see what's known about it, and compare it against similar flagged cases.

WHERE WE'D TAKE THIS NEXT 08 / 09

Where we'd take this next.

  1. Pilot the tools on one line, running alongside current practice before replacing it.
  2. Look into the identical-configuration variance with process and equipment teams — likely a process signal, not a modelling gap.
  3. Revisit the harder-to-call configuration as more test runs accumulate.
  4. Retrain the tool quarterly as new test runs come in, so it doesn't drift from the current line.

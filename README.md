# karthikarumukam-code.github.io

Source of the portfolio site of Karthikeyan Arumugam, served by GitHub Pages.

Plain HTML and CSS. No build step, no framework, no cookies, no trackers, no external fonts.

- `index.html`: home page
- `projects/`: four case studies
- `deep-dives/`: saved working pages linked from the case studies
- `assets/`: stylesheet and images

To preview locally, open `index.html` in a browser, or run `python -m http.server` in this folder and visit http://localhost:8000.
